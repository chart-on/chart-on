# Changelog

Notable changes to the `@chart-on/*` packages. The versioning policy (before 1.0, a minor release may break) is in [`CONTRIBUTING.md`](CONTRIBUTING.md#versioning-and-changelog); upgrade steps for deprecated APIs are in [`docs/upgrading/index.md`](docs/upgrading/index.md).

## Unreleased

### Added

- `@chart-on/core`: quick measure (#43). With `chart.drawings.quickMeasure = true`, Shift+click on an empty part of a pane, with no tool active, starts a temporary date and price measurement that follows the pointer; the next click fixes it, and the click after that, `Escape` or focus leaving the chart removes it (`clearMeasure()` from code). It is no drawing: not saved, copied or undoable, and it fires no `drawings:change`. Shift+drag still draws a selection box. Off by default, pointer only. Sizes (gzip, production): the script-tag build 354,505 to 354,798 B (+293 B), within its budget; a plain `createChart` app is unchanged.

### Changed

- `@chart-on/core`, `@chart-on/ui`, `@chart-on/locales`: the project logo is a small corner badge that links to the project site (#42). With `features.attributionLogo` on (the default), the chart no longer draws the mark in the centre of the main pane or inside the built-in watermark. It shows a faint link to `https://charton.dev` at the bottom of the plot on the start side; on hover or focus it shows in full (it is not a Tab stop) with the name "charton" beside the mark. Its accessible name is the new `attribution` message, translated in the seven locale packs. Screenshots draw the mark and `charton.dev` text in the same corner (`watermark: false` leaves them out). The UI shell's **Logo** switch moved from the appearance panel's Watermark section to its Background section. **Deprecated**: the watermark's `logo` option, removed in 0.3 (see [upgrading](docs/upgrading/index.md#logo-on-watermarkoptions)). Sizes (gzip, production): a plain `createChart` app 85,482 to 85,912 B (+430 B), the script-tag build 354,798 to 355,285 B (+487 B, against main with #43; budget raised from 354,816 to 355,328 B), `@chart-on/ui` `dist/index.js` 105,353 to 105,359 B (+6 B).

### Fixed

- `@chart-on/ui`: in rail flyouts that group tools into sections, each row's hover and active highlight spans the menu width (#45). A tool button inside a section's block box shrank to its icon and label when the shell had no favourites; sections are now grids, so their rows stretch. Sizes (gzip, production): `style.css` 12,800 to 12,795 B (-5 B). No public API change.
- `@chart-on/ui`: trash and remove icon buttons (`.pc-danger`), such as Remove all drawings on the drawing tool rail, use the normal icon colour and show the danger colour only on hover (#49). Sizes (gzip, production): `style.css` 12,795 to 12,787 B (-8 B). No public API change.

## 0.1.0 (2026-10-19)

The first release on npm. This entry describes what each package contains, and the [guides](docs/guide/getting-started.md) cover the details. **Changed** lists what changed for code built from the repository before the release.

- **`@chart-on/core`**: the framework-free chart engine. Candles in fourteen styles, histograms, lines, areas and baselines drawn with WebGL2, heatmaps, volume profiles and custom series ([series](docs/guide/series.md)); panes, normal, log and percent price scales, pan and zoom with inertia ([view and scale](docs/guide/view-and-scale.md)); drawing tools, which can also be sketched freehand (`features.sketch`, with a mouse hold or a touch long-press, `sketch.holdMs`), annotations, reference lines, indicators (with a shared search, `chart.indicators.search(query)`) and compared symbols ([drawings](docs/guide/drawings.md), [indicators](docs/guide/indicators.md)); data sources over REST, WebSocket (reconnecting with backoff), polling, static data and a mock, with a router and caches, and intervals by time, trade count (`'100T'`) or volume (`'5000V'`) ([data sources](docs/guide/data-sources.md)); layouts and storage, bar replay, link groups, a numeric-axis chart, themes with a solid or gradient background, localization with opt-in digit grouping of prices (`localization.grouping`) and right-to-left support (the `direction` option puts the main price axis, legend start and pane buttons on the mirrored side while time keeps running left to right, and canvas text takes its direction from the text), and accessibility down to sonification. Optional features are plugins, so a plain `createChart` bundle leaves them out ([opt-in features](docs/guide/features.md#opt-in-features)), and development warnings fold away in production builds. Also `@chart-on/core/testing` for tests and `@chart-on/core/internal`, which has no stability promise.
- **`@chart-on/ui`**: a batteries-included widget on top of core: the shell with toolbar, drawing tool rail and bottom bar, symbol search, indicator picker, command palette, chart settings (with app-defined fields and actions), schema-driven dialogs, toasts, favourites of any kind (`shell.favorites.of(kind)`), a chart grid, a compact layout and right-to-left chrome, with drawing and indicator style templates as an opt-in add-on entry (`@chart-on/ui/templates`), themed through `--pc-*` CSS variables, with ten colour presets that each have a light and a dark variant (Paper & Ink by default) and a theme that follows the system by default ([UI shell](docs/guide/ui-shell.md), [theming](docs/guide/theming.md)). It has no runtime dependencies: the icons it uses are bundled, with their license in `dist/THIRD-PARTY-NOTICES.txt`. A script-tag build is in `dist/browser/`, with its own notice beside it.
- **`@chart-on/indicators`**: ready-made indicator definitions, from moving averages and bands to oscillators, Ichimoku and moon phases ([indicators](docs/guide/indicators.md)).
- **`@chart-on/locales`**: opt-in translations of the core and shell text, including the chart settings dialog and the appearance panel (#798), one entry per language: German (`@chart-on/locales/de-DE`), Spanish (`@chart-on/locales/es-ES`), French (`@chart-on/locales/fr-FR`), Indonesian (`@chart-on/locales/id-ID`), Japanese (`@chart-on/locales/ja-JP`), Simplified Chinese (`@chart-on/locales/zh-CN`) and Traditional Chinese as used in Taiwan (`@chart-on/locales/zh-TW`); apps that do not import a pack ship none of it ([localization](docs/guide/localization.md#locale-packs)).
- **`@chart-on/ta`**: dependency-free technical-analysis functions over `Float64Array` for indicator authors ([technical analysis](docs/guide/technical-analysis.md)).
- **`@chart-on/react`**, **`@chart-on/vue`**, **`@chart-on/svelte`**: components that mount a chart or a shell, with server rendering support ([frameworks](docs/guide/frameworks.md)), and client-rendered and server-rendered example apps for the wrappers in `examples/`.
