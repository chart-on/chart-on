# @chart-on/ui

Config-driven toolbar, drawing tool rail and shell for @chart-on/core.

Part of [charton](https://github.com/chart-on/chart-on#readme), a WebGL2 charting library.

```bash
npm install @chart-on/ui @chart-on/core
```
