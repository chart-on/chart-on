# @charton/indicators

Built-in chart indicators (SMA, EMA, Bollinger Bands, VWAP, RSI, MACD, volume MA, cumulative volume, Keltner, Donchian, Supertrend, Ichimoku, ATR, Stochastic, Stoch RSI, DMI/ADX, OBV, moon phases) for @charton/core.

Part of [charton](https://github.com/chart-on/charton#readme), a WebGL2 charting library.

```bash
npm install @charton/indicators @charton/core
```
